# 06. Навигация

## Лента экранов

Пять экранов стоят в ряд, «как карточки на столе». Главная — в центре, приложение открывается на ней.

```
            Медитации                         Избранные
               ▲ свайп вверх                     ▲ свайп вверх
               │ ▼ свайп вниз                    │ ▼ свайп вниз
Анатомия ◀▶ Техники ◀▶ ГЛАВНАЯ ◀▶ Подбор специалиста ◀▶ Доброе слово
   0           1           2               3                  4
```

| Жест | Где | Что происходит |
|---|---|---|
| Свайп влево/вправо | Анатомия, Техники, Главная, Доброе слово | Соседний экран ленты. На краях (Анатомия слева, Слово справа) — мягкий упор, без зацикливания |
| Свайп влево/вправо | **Подбор специалиста** | Листает карточки: вправо — «Нравится», влево — «Не подходит». Лента не двигается |
| Свайп вниз | Техники | Открывает Медитации (экран выезжает сверху) |
| Свайп вниз | Подбор специалиста | Открывает Избранные (выезжает сверху) |
| Свайп вверх | Медитации, Избранные | Возврат на Техники / Подбор |
| Тап по пункту индикатора | Все экраны ленты, Медитации, Избранные | Переход на экран ленты (на Медитациях/Избранных — сначала закрыть их) |
| Тап по PullHint | Техники, Подбор, Медитации, Избранные | То же, что свайп вниз/вверх — для тех, кто не догадается |

Порог свайпа: 60 dp или скорость > 500 dp/с; горизонтальный свайп засчитывается, только если смещение по X больше, чем по Y. Вертикальный свайп вниз ловится, только когда список на экране прокручен в самый верх (иначе это прокрутка).

### Реализация

- Одна страница `app/(app)/index.tsx` с компонентом `FeedPager`: 5 страниц в ряд, `GestureDetector` + `Gesture.Pan()` из Gesture Handler, смещение — `useSharedValue` + `withTiming(…, { duration: 240, easing: Easing.out(Easing.cubic) })`. Страницы монтируются лениво, соседние держатся в памяти.
- Текущий экран — в параметре URL `?s=anatomy|techniques|home|match|word` (`router.setParams`). Так работают ссылки в вебе и возврат на нужный экран после стека.
- На странице «Подбор» пейджер отключает свой горизонтальный жест, пока активна колода карточек (`Gesture.Pan().enabled(page !== 3)` или `blocksExternalGesture` у жеста колоды).
- Медитации (`/meditation`, доступна без входа) и Избранные (`/favorites`) — отдельные маршруты с анимацией появления сверху: `Stack.Screen options={{ animation: 'slide_from_bottom' }}` не подходит по направлению, поэтому — `presentation: 'transparentModal'` + своя анимация `translateY` от −высоты экрана к 0 (320 мс) и жест закрытия вверх.
- Параметры медитации: `/meditation?tab=breath|pomodoro&scheme=4-6|4-7-8|5-5-5&cycles=N&from=feed|sos|technique`. Открыта из ленты (`from=feed`) — PullHint «Свайп вверх — к техникам» и индикатор ленты, как в макете. Открыта из SOS или техники — вместо PullHint шапка «Назад» (возврат на предыдущий экран), индикатора нет.
- **Веб:** мышью свайпы работают через тот же Pan; дополнительно стрелки ← → на клавиатуре переключают экраны ленты, а индикатор — основной способ навигации.
- **Уменьшить движение:** смена экрана без сдвига — мгновенно с кроссфейдом 120 мс.

## Кнопка SOS

- Экраны ленты: круглая `SosRound` 48×48 справа в шапке (на Главной — круглая 72 рядом с «Картой»).
- Медитации, Pomodoro, Избранные: `SosRound` справа в строке PullHint (в макетах её нет — добавить).
- Остальные экраны: `ScreenHeader` с кнопкой «SOS» справа.
- Исключения: онбординг (там номер 133 в тексте OnbWarning — ссылка `tel:133`), сам SOS и кабинет специалиста.
- SOS открывается поверх текущего экрана (`router.push('/sos')`) и доступен **без входа в аккаунт**.

## Системная кнопка «Назад» (Android) и жест «назад»

| Где | Что делает |
|---|---|
| Экран ленты, кроме Главной | Переход на Главную |
| Главная | Выход из приложения (стандартное поведение) |
| Медитации, Избранные | Закрыть, вернуться на Техники / Подбор |
| Шторка открыта | Закрыть шторку |
| DASS-21, ответы есть | Шторка «Прервать тест? Ответы не сохранятся» |
| КРИК, идёт замер | Остановить замер, без результата |
| Остальные экраны стека | Обычный `router.back()` |

Используйте `BackHandler` / `useFocusEffect` на экранах ленты.

## Переходы главного пути

```
onboarding/index → warning → gestures → sign-in → university → (app)/?s=home
Главная: КРИК → scream (ready → live → result) → «Отметить, как вы теперь» → Главная, фокус на лицах
Главная: «Тест DASS-21» → dass (21 вопрос) → dass/result
dass/result: «Подобрать специалиста» → (app)/?s=match;  «Помощь в моём вузе» → sos/university
Подбор: «Нравится» / свайп вправо → specialist/[id] с плашкой «Контакты открыты» → телефон (tel:)
Любой экран: SOS → sos → «Позвонить 133» (tel:133)
```
