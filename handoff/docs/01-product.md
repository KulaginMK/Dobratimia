# 01. Продукт

## Что это

«Добратимия» — бесплатное приложение для студентов медицинских вузов Беларуси (17–25 лет, будущие врачи). Это безопасное место, где можно выдохнуть:

- **понять своё состояние** — тест DASS-21 и дневник настроения;
- **снять напряжение здесь и сейчас** — КРИК (выпустить пар голосом или текстом), дыхательные практики, медитации, Pomodoro, техники самопомощи, «Анатомия стресса»;
- **найти живую помощь** — подбор психолога свайпами, контакты психологической службы своего вуза, экстренный номер.

## Рамки первой версии

- Платформы: Android (Google Play) и веб из одного кода. iOS пока не делаем, но код не должен ему мешать.
- Язык интерфейса: только русский. Страна: только Беларусь. Вузы: ВГМУ, БГМУ, ГрГМУ, ГомГМУ и «Другой вуз».
- Вход: Google-аккаунт. Без входа доступны онбординг и SOS.
- Специалисты: аккаунты создаёт только администратор. Специалист редактирует свою карточку (правки проходят проверку администратора), администратор — любую.
- **Переписки в приложении нет.** Студент ставит специалисту «Нравится» → у студента открываются контакты специалиста, специалист попадает в «Избранные». Специалист видит только число отметок, не видит, кто их поставил.
- Главная: бегущая строка показывает только счётчик «Сегодня вы не одни: N человек».
- «Анатомия стресса»: 2D-иллюстрация с органами и текстом. 3D-модели из старой веб-версии не переносим.
- Карта: заглушка с кнопкой «Открыть карту в Google Maps». Встроенная карта — позже и только в веб-версии.
- Всё бесплатно: никаких покупок, подписок и рекламы.

## Принципы (они же — критерии приёмки)

1. Добрый тёплый тон, без нотаций и стыда. Обращение на «вы».
2. Минимум данных. Ответы тестов, дневник и КРИК хранятся только на устройстве.
3. Никаких диагнозов и медицинских обещаний. Тест — ориентир, а не заключение.
4. Экстренная помощь доступна с любого экрана в одно касание.
5. При высоких баллах — бережно предложить живую помощь: «Подобрать специалиста» и «Помощь в моём вузе».
6. Никаких серий, штрафов и «вы пропали на 3 дня». Тимка никогда не стыдит.

## Что не делаем в первой версии

- Чат и сообщения между студентом и специалистом.
- Оплату, запись на приём внутри приложения (у специалиста может быть ссылка на внешнюю онлайн-запись).
- 3D-анатомию, встроенную карту в Android-версии.
- Английский язык, другие страны.
- Сбор аналитики поведения. Допустим только счётчик посетителей за день (см. 08).

## Главный путь (по нему принимают прототип и первую версию)

Онбординг → главная → свайпы по ленте → КРИК → DASS-21 с результатом → подбор специалиста → «Нравится» → контакты → SOS.

Кликабельный прототип этого пути — артефакт «Добратимия — экраны приложения» (Design), кнопка Play на экране 1.1. Скриншоты всех экранов — `reference/screens-png/`.
