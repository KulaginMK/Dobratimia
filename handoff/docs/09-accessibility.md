# 09. Доступность

Цель — WCAG 2.2 AA и рекомендации Android по доступности. Аудитория — уставшие люди, часто в стрессе, иногда ночью: крупно, контрастно, предсказуемо.

## Обязательно

- **Касание ≥ 48×48 dp** для всего нажимаемого. Если элемент визуально меньше (чип 40, ссылка «Дневник») — `hitSlop`.
- **Подписи.** Кнопка только с иконкой — `accessibilityLabel` («Позвонить Ольге Мирошник», «SOS — экстренная помощь», «Сохранить фразу»). Декоративные иконки скрыты (`Icon` без `title` уже скрыт).
- **Роли и состояния:** `accessibilityRole` (`button`, `link`, `tab`, `switch`, `radio`, `progressbar`, `header`), `accessibilityState` (`selected`, `checked`, `disabled`). Заголовок экрана — `accessibilityRole="header"`.
- **Контраст** — только токенами; пары проверены. Новое сочетание — проверить ≥ 4,5:1 для текста и ≥ 3:1 для границ и иконок.
- **Цвет не один:** уровень DASS-21 подписан словом, настроение — словом под лицом, тост — иконкой, ошибка поля — текстом.
- **Масштаб шрифта:** не отключать `allowFontScaling`. Проверить экраны при системном шрифте 130% и «Крупный»: ничего не обрезается, кнопки растут в высоту, тексты переносятся. Ограничить рост только в индикаторе ленты (`maxFontSizeMultiplier={1.3}`).
- **Уменьшить движение** (`useReducedMotion()` из Reanimated): лента — без сдвига, шторки — появление прозрачностью, бегущая строка стоит, скелетоны не пульсируют, рассыпание текста в КРИКе — просто исчезновение. Дыхательный круг остаётся (это сама практика), но без лишних эффектов.
- **Жесты всегда дублируются кнопками:** свайпы ленты — индикатор; свайп вниз — PullHint; свайп карточки — «Нравится» / «Не подходит»; свайп шторки — крестик.
- **TalkBack:** лента объявляет «Главная, экран 3 из 5»; при смене экрана фокус переходит на заголовок нового экрана. Таймеры (дыхание, Pomodoro, КРИК) объявляют смену фазы через `AccessibilityInfo.announceForAccessibility`, а не каждую секунду.
- **Порядок фокуса** совпадает с визуальным: шапка → содержимое → индикатор.
- **Веб:** видимое кольцо фокуса `color.focus` 2 px с отступом 2 px; всё доступно с клавиатуры; стрелки ← → переключают ленту.

## Проверка перед каждым релизом

1. Пройти главный путь (docs/01) с TalkBack, не глядя на экран.
2. Пройти главный путь при шрифте 130% и в тёмной теме.
3. Пройти главный путь в вебе только клавиатурой.
4. Включить «Уменьшить движение» (Настройки → Специальные возможности → Удалить анимацию) и проверить ленту, шторки, КРИК.
5. Android Accessibility Scanner на Главной, Подборе, SOS, DASS-21.
