# Card

Карточка — контейнер для техник, специалистов, результатов и бережных сообщений.

- `variant`: `surface` — белая с мягкой тенью, по умолчанию; `soft` — терракотовая подложка для дружеских сообщений; `outline` — плоская с рамкой для списков в настройках; `sos` — бережный блок при высоких баллах DASS-21.
- `interactive` + `onClick` — карточка нажимается целиком (техника, специалист) и рендерится кнопкой.
- Содержимое передаёт потребитель: иконку, заголовок `h3`, подпись `caption`. Внутренний отступ — `space.lg`, между карточками — `space.md`.
