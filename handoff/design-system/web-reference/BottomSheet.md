# BottomSheet

Нижняя шторка поверх экрана с затемнением `color.scrim`: выбор вуза, мини-карточка автора фразы, фильтры.

- `title` — заголовок шторки; `onClose` — крестик и нажатие на затемнение; `open` — показывать или нет.
- `inline` — шторка внутри родителя (для превью и вложенных областей); без него — поверх всего окна.
- Верхние углы `radius.2xl`, ручка сверху, тень `shadow.lg`. В приложении закрывается и свайпом вниз.
- Содержимое передаёт потребитель. Высота — по содержимому, не больше 88% экрана.
