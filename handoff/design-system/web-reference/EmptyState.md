# EmptyState

Пустое состояние: Тимка, заголовок, одна фраза и одно действие. Для дневника без отметок, избранных контактов, закончившихся специалистов.

- `title` — что здесь будет («Здесь пока пусто», «Специалисты закончились»).
- `text` — одна тёплая фраза, что сделать дальше.
- `pose` — обычно `sleep`; `hello` — если пусто, потому что это первый вход.
- `actionLabel` + `onAction` — одно действие, кнопка `primary`.
