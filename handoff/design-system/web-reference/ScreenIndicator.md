# ScreenIndicator

Индикатор ленты экранов внизу: Анатомия ← Техники ← Главная → Специалисты → Слово. Показывает, где вы в ленте, и по нему можно перейти к любому экрану.

- `variant`: `labels` — точки с подписями под ними; `dots` — только точки, активный экран подписан.
- `screens` — названия слева направо; `current` / `defaultCurrent` — индекс; `onSelect(index)` — переход.
- На «Подборе специалиста» свайп листает карточки, поэтому уйти с экрана можно только через индикатор. Индикатор не прячется.
- `hrefs` — ссылки на экраны в том же порядке; пункты становятся ссылками. Нужно для веб-версии и прототипа.
- Каждый пункт — кнопка 48×52 с `aria-current="page"` у активного.
