# Toast

Короткое уведомление внизу экрана над индикатором ленты. Исчезает через 4 секунды, с действием — через 6.

- `message` — одна короткая фраза.
- `tone`: `neutral`, `success` (галочка), `error` (крестик). Тон всегда подкреплён иконкой и словом.
- `actionLabel` + `onAction` — одно действие, например «Повторить» или «Отменить».
- Для ошибок роль `alert`, для остальных — `status`.
