# TextField

Поле ввода с подписью сверху, подсказкой или ошибкой снизу.

- `label` — всегда виден, плейсхолдер подписью не считается.
- `hint` — пояснение; `error` — текст ошибки, который говорит, что сделать («Не хватает цифр — проверьте номер»).
- `multiline` + `rows` — для «Выплеснуть текстом» и описания в карточке специалиста.
- `type="tel"` для телефона, `type="url"` для Telegram и записи.
- Работает в контролируемом (`value` + `onChange`) и неконтролируемом (`defaultValue`) режимах.
