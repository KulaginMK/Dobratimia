# Switch

Переключатель с подписью — для напоминаний и настроек профиля.

- `label` — что включается; `description` — расписание или пояснение.
- Включённое состояние — `color.primary` с галочкой, выключенное — серая рамка `color.borderStrong` (3:1 к фону). Состояние читается не только по цвету.
- Вся строка 56 px, сам переключатель 56×32 внутри области касания 48.
