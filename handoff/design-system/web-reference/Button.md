# Button

Кнопка. Текст начинается с глагола: «Позвонить», «Отметить настроение», «Ещё».

- `variant`: `primary` — главное действие экрана, одна на экран; `secondary` — мягкое второстепенное («Напомнить завтра»); `outline` — отмена и нейтральные действия; `text` — ссылки и «Подробнее»; `sos` — только экстренная помощь; `deep` — крупный акцент вроде кнопки DASS-21 на главной.
- `size`: `md` (52) или `lg` (64). На всю ширину — `fullWidth`.
- `icon` / `iconRight` — имя иконки. Для кнопки только с иконкой обязателен `aria-label`.
- `href` превращает кнопку в ссылку (например, `tel:133`).
- В «Подборе специалиста» пара «Не подходит» / «Нравится» — это `outline` и `primary` размера `lg`.
