# Chip

Чип — короткая метка-переключатель: специализации специалиста, фильтры, режим «Сахарный / С перчиком» в «Добром слове».

- `selected` / `defaultSelected` + `onChange`. Выбранный чип — `color.primarySoft` с рамкой `color.primary` и галочкой.
- `icon` — иконка вместо галочки, например message для «Онлайн».
- В карточке специалиста чипы только показывают специализации и не нажимаются: используйте `disabled` или отдельный бейдж.
