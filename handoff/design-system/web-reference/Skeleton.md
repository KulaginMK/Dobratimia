# Skeleton

Заглушка загрузки в форме будущего контента — вместо спиннера на весь экран.

- `variant`: `text` (строки, `lines`), `listItem` (иконка и две строки, для списка техник и контактов), `card` (`height`), `circle` (`size`, для фото специалиста).
- Цвет `color.skeleton`, мягкая пульсация 1,6 с. Если включено «Уменьшить движение», пульсации нет.
- Скелетон показывается, если загрузка дольше 300 мс.
