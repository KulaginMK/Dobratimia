# Icon

Иконка в стиле «мягкие формы»: основная часть сплошная, вторая — тем же цветом с прозрачностью 32%. Цвет наследуется (`currentColor`).

- `name` — одна из 19 иконок: home, scream, breath, techniques, diary, specialist, map, sos, phone, message, heart, sprout, bell, close, chevronRight, chevronLeft, check, play, pause.
- `size` — 24 в интерфейсе, 32 в списках, 40+ в пустых местах.
- Если иконка единственное содержимое кнопки, подпись ставится на кнопку (`aria-label`), а иконка остаётся декоративной. Если иконка несёт смысл сама по себе, передайте `title`.
- Эмодзи вместо иконок не используем.
