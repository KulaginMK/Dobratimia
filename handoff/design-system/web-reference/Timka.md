# Timka

Тимка — маскот, тёплое зёрнышко с ростком. Встречается только в онбординге, медитациях и пустых состояниях.

- `pose`: `hello` — машет, для онбординга и первого входа; `breathe` — дышит, для медитаций (кольцо `color.primarySoft`); `sleep` — спит, для пустых состояний.
- `size` — размер в px, обычно 120–200.
- Тимки нет в SOS, результатах DASS-21, у специалистов и в ошибках.
- Тимка не грустит и не стыдит, если человек долго не заходил.
