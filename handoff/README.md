# Пакет передачи «Добратимии» в Claude Code

Здесь всё, что нужно Claude Code, чтобы написать приложение на Expo (React Native, TypeScript) по готовому дизайну: правила, спецификации, токены, готовый код темы и бренд-компонентов, ассеты и эталоны всех экранов.

## Как начать

1. Распакуйте архив в корень репозитория `KulaginMK/Dobratimia`. Должно получиться:
   ```
   Dobratimia/
     CLAUDE.md      ← Claude Code читает его автоматически
     handoff/       ← этот пакет
     web/           ← старая веб-версия, не трогаем
   ```
2. Закоммитьте и запустите Claude Code в папке репозитория.
3. Откройте `handoff/docs/11-roadmap.md` и отправляйте промпты по одному этапу.

## Что внутри

| Папка | Что это |
|---|---|
| `docs/` | 11 спецификаций: продукт, бренд, токены, компоненты, экраны, навигация, функции, данные и бэкенд, доступность, заглушки, план с промптами |
| `reference/screens-png/` | 39 скриншотов экранов (светлая и тёмная тема) — так должно выглядеть |
| `reference/screens-html/` | Разметка тех же экранов: точные тексты и размеры |
| `reference/kitchen-sink.png` | Как выглядят готовые тема и бренд-компоненты, запущенные в Expo |
| `design-system/` | `tokens.json` (источник правды), брендбук, веб-эталон компонентов |
| `src/` | Готовый код: тема (светлая/тёмная, шрифты) и компоненты Logo, Timka, Icon, Button. Проверено в Expo SDK 57: TypeScript без ошибок, веб-сборка отрисовывается (см. kitchen-sink.png). На Android-устройстве ещё не запускалось — это первый шаг этапа 1 |
| `assets/svg/` | Логотип (4 варианта), иконка приложения, Тимка (3 позы), 19 иконок |
| `assets/app/` | PNG для app.json: иконка 1024, adaptive icon (передний план и монохромная), сплэш светлый и тёмный, иконка Google Play 512, favicon |
| `tools/` | Скрипты, которые пересобирают тему и SVG-фигуры, если меняются токены или иконки |

## Что решить до или во время разработки

Полный список — `docs/10-placeholders.md`. Главное:

- **Тексты DASS-21.** Нужна валидированная русскоязычная версия в стандартном порядке. Список из старой веб-версии не подходит: порядок утверждений не совпадает с ключом подсчёта.
- **Контакты служб вузов** — в макетах вымышлены.
- **Бэкенд.** Рекомендован Supabase. Проверьте доступность из Беларуси и требования закона о персональных данных. Данные о здоровье по схеме не уходят с телефона.
- **Политика конфиденциальности и согласие** — нужен юрист.
