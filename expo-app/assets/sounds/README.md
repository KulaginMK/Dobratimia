# Фоновые звуки для дыхания

Все три записи — с [BigSoundBank](https://bigsoundbank.com), автор Joseph Sardin, лицензия **CC0** (общественное достояние): можно использовать в любом приложении, в том числе платном, без указания автора. Лицензия проверена на страницах записей 17 октября 2026 года.
