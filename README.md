# smm-media

Служебная ветка: картинки и видео для публикаций Добратимии в Instagram.
Metricool забирает файлы отсюда по прямым ссылкам raw.githubusercontent.com.
Источник правды — Google Drive, папка «Добратимия/СМИ посты/02 Публикации».
Сайт и код приложения живут в ветке main, эта ветка с ними не связана.
