2. Как появляется кабинет специалиста

Аккаунт специалиста открывает только администратор. Сначала он смотрит ваш диплом — копию диплома мы не храним. Затем администратор вписывает адрес вашей Google-почты, и при входе с этой почтой в приложении открывается кабинет. В кабинете вы заполняете карточку; каждое изменение публикуется после проверки администратором.

4. Что мы публикуем

4.1. Опубликованная карточка видна всем пользователям приложения, в том числе тем, кто не вошёл. Публикуя карточку, вы соглашаетесь, что эти сведения становятся доступны неограниченному кругу людей.

4.2. Контакты студенты видят только после отметки «Нравится» и только пока включено «Согласие на публикацию контактов». Переключатель, как и другие правки карточки, вступает в силу после проверки администратором. Если нужно скрыть контакты срочно, напишите нам на dobratimia@gmail.com.

4.3. Ссылка «Записаться» ведёт на сайт, который вы указали. Что этот сайт делает с данными студентов, регулируют его правила.

5. Кто ещё получает данные

5.1. Мы не продаём персональные данные и не используем сервисы аналитики. Данные получают только сервисы, без которых приложение не работает:

  • Supabase (Supabase, Inc.) — сервер приложения: база данных, вход и хранилище фото. Данные хранятся в регионе ЕС (Франкфурт, Германия). Технические журналы запросов и входов с IP-адресами Supabase на нашем тарифе хранит 1 день.
  • Google (Google LLC) — вход через аккаунт Google; Gmail — почта, на которую приходят ваши письма.
  • GitHub (GitHub, Inc.) — размещает веб-версию приложения и записывает IP-адреса посетителей сайта в целях безопасности.

5.2. Доступ ко всем данным на сервере есть только у администратора — владельца приложения — через панель Supabase.

5.3. Мы можем передать данные государственным органам, только если этого требует закон.

6. Передача данных за границу

Сервер Supabase находится в Германии: данные карточки и фото хранятся там с вашего согласия. Google и GitHub — компании из США; данные, которые они получают напрямую от вас при входе и при открытии сайта, обрабатываются по их правилам.

8. Как мы защищаем данные

  • Приложение обменивается данными с сервером только по защищённому соединению HTTPS.
  • Правила доступа в базе данных: ваша почта студентам не видна; контакты получает только тот, кто вас отметил, и только при вашем согласии; предлагать правки карточки можете только вы, а публикует их только администратор; фото загружается только в вашу папку хранилища.
  • Число отметок вы получаете без имён тех, кто их поставил.
  • Черновик карточки сервер принимает только из известных полей и не больше 20 000 знаков.

Ни один способ защиты не исключает риск полностью. Если произойдёт утечка, мы сообщим о ней в Национальный центр защиты персональных данных в сроки, установленные законом.

9.1. Выключить показ контактов можно в кабинете: «Согласие на публикацию контактов». Изменение вступит в силу после проверки администратором (пункт 4.2).

9.2. Чтобы снять карточку с публикации, удалить её, контакты и все фото, напишите на dobratimia@gmail.com с почты вашего аккаунта. Мы сделаем это в сроки, установленные Законом № 99-З.

9.3. Кнопка «Профиль» → «Удалить мои данные» удаляет ваш аккаунт и сессии входа, но не карточку: карточка перестаёт быть связана с аккаунтом. Чтобы удалить и её, напишите нам (пункт 9.2).
